# 《道德经》全篇审校与《学习观》模型关系

本次继续审阅数据库内同一现代工作文本的全部 254 个原文单元及已有关系，不替换成另一校本，不补读待核字形。聚合文档仍保留原有命题阅读层；手工联结模型层使用《学习观》已有的类型与端点约定，不能声称整份旧图已自动转换成本体 `learning-view-v1`。

上一版的 71 条 `source_relation` 只是带引文的自定义概念对应，不属于《学习观》的 21 类关系。本次明确删除这些活动边，保留其原图版本。旧类型仅供历史读取，画布标注“旧版原文对应（待整理）”，不再以引文摘要作为关系类型名。

每个可确认的映射分别建 `rule`，源句作为 `relation_material`：材料以 `states_mapping` 交代规律/模型，以 `builds` 表达本次阅读整理所使用的模型材料；`connection_model → concept` 的 `maps_between` 明确输入/输出；模型及相关概念以 `has_rule` 引用规律。仅明确的复合序列使用 `rule → rule` 的 `composes`，不把并列项拼成因果链。原句、完整条件和解释边界绑定实际模型分支，仍为待审校的文本主张，不升级为已认证经验定律。

`has_rule` 可携带经验证的 `modelId`、`branchId`、`statement`、`condition`、`boundary`；目标必须是该分支的逐字规律，源必须是记录的模型或其中的概念。Host 与 SQLite 均核对字段、出处和分支，重启后保留长条件和边界。画布显示“规律”等真正的本体关系名，详情显示映射、条件、边界及全部引文；不能把这些字段直接改标成因果。

审校清单在 `scripts/fixtures/dao-learning-audit.mjs` 与已审的旧清单中。准备器 `scripts/kg-dao-learning-audit.mjs` 是纯函数/只写本地审计输出的 dry run：要求准确文档、254 单元原文指纹与 71 个旧对应；审查版本已应用或原文改变时拒绝重复覆盖。它产出每一段的原文指纹、关系清单、明确删改项及 `expectedRevision` 补丁。

具体修正包括水胜刚/弱胜强的输出与比较对象混淆、舍葆必死的合取前提、六种相待关系与五种同级观照的区分、圣人为/成功的不同限定、玄德同名异语境的定义，以及“可以有国”不作为已然有国接入下一步。补入得一、治理回应、守持、啬积德、知常、法则、复归、命名等可逐字核对的映射；64 条原有跨段关系补齐两端出处。疑义、编辑说明、反问或仅主题相似的段落保留原记录和边界，不为连通率造边。
