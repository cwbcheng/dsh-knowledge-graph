# 渐构靶图

## 与书中结构的对应

依据《学习观》“渐构靶图”一节及图 34-3 至图 34-8，实现个人学习工作台，而非另一种正式图谱抽取。

- 上层是学习者记录的输入概念及内涵、映射规律、输出概念及内涵；条件、边界和不确定处另列。
- 下层保留完整情境、每一个必要输入、具体推测过程和输出。输入、输出各有独立槽位身份，不按同名合并。
- “可能的输出范围”是记录的陪域，不是由当前例子反推的值域。多个例子可以指向同一取值，也保留尚无例子指向的取值。
- 概念与判别模型使用“万物到 A 或非 A”模板；联结模型使用输入到输出模板。没有已核对方向时，输入、输出名称留空，不从边或节点顺序猜测。
- 例子的细节可展开；下层输入、输出按钮将对应上层槽位滚入视野并移入键盘焦点，而非只在屏幕外高亮。槽位的返回箭头回到刚才那个例子的具体输入或输出，必要时展开该例子；同名槽位和共用槽位的不同例子仍按独立身份区分。资料目标和个人表述分开，原文入口返回该节点的材料视图。

下层跳到上层前临时记录入口在各层滚动容器中的位置，返回时恢复同一例子、同一输入或输出的阅读位置，而不是一律居中。上层内容变高后仍按身份定位，窗口变矮时将入口限制在可见区域；只读快照及旧版草稿也可往返。原滚动容器更换或位置不可用时，只回退到该明确入口；入口缺失或重复时不跳到同名替代项。历史读取、字段对照、文档/目标/版本/草稿基线变化、隐藏、卸载和重读使旧跳转失效，过期表单回调不能改变当前阅读点。位置仅在本次下上往返中保留，不写草稿、导航缓存或服务器，也不是整页刷新或任意编辑区的滚动恢复。

## 按输出找例子

陪域取值旁的向下按钮可直接定位到下层，并只显示记录中对应此取值的例子；下层菜单也可选择全部例子或含未对应取值输出的例子。对应关系同时核对输出槽位与取值的完整身份，不凭同名、情境中的词语或输出细节猜测。选中后显示准确身份，多个必要输入和其他输出仍作为完整例子保留。

计数仅表示当前记录中的对应情况，不表示预测正确或验证通过；没有对应例子的取值仍保留在陪域中，不据此认定该取值不可能。筛选隐藏而不删除例子，已展开细节和未保存文字保留；新增例子先返回全部范围，避免空白例子被筛选隐藏。

编辑当前可见例子的输出或阶段后，如果它不再符合所选筛选，只解除不再匹配的那一项筛选并明确提示，保留当前展开状态和编辑焦点，不让表单在填写途中消失。更改无关字段、另一输出或仍有未对应输出时，原筛选继续保留；同名取值仍按完整身份判断。只改本地草稿中的明确字段，不自动保存或恢复批准；旧上下文、旧草稿、隐藏例子及忙碌/历史读取中的过期编辑回调不能改写当前草稿或清除筛选。

浏览不发出额外 HTTP 或模型请求，不写草稿或服务器、不授予保存批准。草稿与历史快照各自筛选，历史返回及读取失败保留草稿筛选；旧版草稿和历史只读限制不变。文档、目标、版本、草稿基准、隐藏或重读改变后清除当前筛选；卸载后的旧回调不能定位到另一个对象，新挂载只按下述规则恢复导航意图。此处按记录中的输出对应浏览，不判断适用分支是否成立，也不是任意条件的语义检索。

## 按记录阶段找例子

下层可按学习材料、预测草稿、已记录但待对照的预测、对照草稿、已记录对照筛选，与输出取值筛选取交集。选择已记录预测后可直接填写对照结果；阶段改变时保留当前编辑表单及仍匹配的输出筛选，焦点从消失的开始按钮移到对照填写区。上层陪域的向下入口显示该取值计数包含的全部例子；新增例子解除当前例子筛选，避免空白例子不可见。

“已记录”要求当前草稿基线或所看历史快照中有同身份、同阶段、同情境/接触声明/完整输入输出/过程的记录，对照还须核对反馈类型、正文及来源。仅同名、同 ID、表单填写完整或本地缓存声明都不能证明已经保存。若旧版或冲突草稿的基线记录未在当前读取结果中，则列为“保存状态待核对”，不猜成已保存或尚未保存；查看对应历史快照仍使用那一版自身的状态。

阶段不是验证结论：个人判断、资料答案、观察记录和 AI 建议仍分别标明，已记录对照也明确“未独立验证”。空结果只是该筛选组合没有记录，不表示情境不可能或已全部验证。筛选仅本地浏览，不改草稿、记录或批准，不触发自动保存或模型调用；错误重试、旧回调和文档/版本隔离与输出筛选一致。

## 按对照来源找例子

「按对照来源查看例子」按已进入对照阶段的实际来源类型筛选个人判断、资料答案、观察记录和 AI 建议；「尚未进入对照阶段」只包含材料与预测，不借用将来反馈或非对照阶段的默认来源字段。只读来源声明，不从情境文字、来源说明或概念名称猜测类型。同名例子保持独立身份。

来源、记录阶段、输出取值与文字查询四项取交集。来源本身不证明已保存、真实、独立验证或掌握，未保存反馈仍标为对照草稿，旧版或冲突基线的保存状态仍待核对。历史快照使用自身的阶段和来源，不套用最新修订的答案。空筛选结果不等于没有反例或已经验证。

编辑来源或开始填写对照结果使当前例子不再匹配时，只解除失效的筛选，保留有效维度和同一个编辑控件。上层取值入口与新增例子重置来源筛选。草稿与历史临时筛选互不覆盖，返回或失败重试保留原草稿；纯筛选不写个人内容或发起保存请求，不改变保存批准。

## 搜索例子文字

下层的文字搜索覆盖当前草稿或单份历史快照中每个例子的完整情境、各必要输入、具体输出细节、推测过程，以及已进入对照阶段的结果正文和来源说明。搜索不截断长字段，忽略字母大小写，但保留空格、标点和运算符；不把多个字段拼成一句话，不执行正则、公式或语义推断。展开命中的例子后标出实际命中字段，完整输入输出及限定语仍保留。

文字、输出取值、记录阶段和对照来源四项取交集，不靠同名合并身份。文字命中不证明条件满足，空结果不证明情境不可能或已经验证；当前历史快照不会搜到后来新增的对照答案。槽位名称、上层表述与陪域取值名称不是例子自身的文字，不参与此处检索。

查询只影响浏览，不改草稿、保存批准或服务器记录，不发额外请求。显式编辑使当前例子失去唯一文字命中时，只清除失效的查询，保留仍有效的输出/阶段筛选以及同一个展开编辑控件；无关字段的修改不清除查询。上层取值入口和新增例子清除查询，避免计数对应的例子或空白表单被暗中隐藏。草稿与历史查询独立，错误重试和返回保留草稿查询；文档/目标/版本切换、隐藏或重读后清除当前筛选。

## 刷新后恢复例子筛选

同一标签页整页刷新后，重新进入同一文档、同一目标的渐构靶图，可以恢复当前草稿的文字查询、输出取值、记录阶段和对照来源组合。只记录导航意图，按完整文档/图谱版本/目标以及草稿基准版本和父记录身份核对；不缓存例子、服务器响应、历史快照、个人表述或批准，不自动打开旧版本草稿。旧导航未包含来源字段时兼容为全部来源，非法类型不能恢复为验证或权威状态。

必须重新读取当前靶图后才应用筛选，已保存/未保存状态重新按实际记录字段计算。首次读取失败保留待恢复条件与原草稿，显式重试成功后恢复；基准或父记录不符则取消恢复。输出身份已不存在时，仅回到全部输出，不按同名替换，其他有效筛选保留。字面查询的大小写、空白和运算符保持原值。

历史快照中的筛选不覆盖草稿导航，刷新也不自动重开旧快照。编辑使查询失效、新增例子或显式清空后的结果会更新导航，不在刷新后复活旧查询。导航与既有标签页导航共用独立存储及错误提示；关闭或清理会话后不保证恢复。筛选恢复不是阅读滚动点恢复，也不代表验证通过或掌握。

## 保留例子的展开与折叠

例子按完整身份记录展开或折叠选择，不靠情境文字或显示序号。筛选暂时隐藏例子后恢复范围，仍保留该选择；从历史返回未保存草稿时也恢复草稿自己的展开状态。历史快照与草稿、两份不同历史快照不会因为复用例子 ID 就共用 DOM 状态，同一快照从字段对照返回内容时保留本次展开选择。

新建的当前版本例子默认展开，方便填写；主动折叠后不因其他字段编辑而重开。旧版、冲突或历史例子不因当前记录缺少相同 ID 而被当成新建例子自动展开。隐藏、目标/文档/版本/草稿基线变化或重读清除当前临时展开状态；迟到、隐藏例子及脱离 DOM 的折叠事件不能改写另一上下文。

同一标签页整页刷新时，草稿例子的展开选择随现有筛选意图恢复，仍须实际读取成功、文档/目标/版本和草稿基线完全匹配。只缓存最多 40 个例子 ID 与布尔值，不缓存情境、答案、历史响应或批准。旧导航缺少此字段时兼容默认行为；非法列表拒绝恢复，已经不存在的身份忽略，不按同名替代。读取失败保留待恢复意图和原草稿，重试成功后恢复；纯展开不写草稿或服务端，不改变批准。这不是精确滚动位置恢复、阅读完成或掌握证明。

## 定位和连续浏览例子

下层的「定位例子」按当前输出、阶段、来源和文字筛选的交集列出例子，保留原序号、完整身份及情境摘要。选择后展开并聚焦该例子的标题；已展开例子内的上下箭头按同一筛选结果定位上一个或下一个，首尾不循环。相同情境或名称不会合并，也不会替代已经不存在或不再符合筛选的身份。每次打开的仍是完整例子，不丢弃其他必要输入、输出、单位或对象时间说明。

定位只改变本地浏览状态，不改草稿文字、已存记录或保存批准，不额外读取服务器或调用模型。草稿、历史快照和旧版只读草稿均可浏览，原有写入限制保持不变。空筛选和读取期间不可定位；字段对照、目标或版本切换、隐藏、重读以及筛选变化使旧定位请求失效。切回同一个目标或筛选，也不复活此前留下的点击回调。

展开选择按已有导航规则保留；定位菜单的选中项只属于本次浏览，不另存为阅读进度，刷新后不自动跳转。定位、展开或逐条经过例子不代表阅读完成、预测正确或掌握。

## 对照两个例子

下层的「对照两个例子」可从当前草稿或正在查看的单个历史快照中，明确选择两个不同身份的例子。默认逐字段展示两侧的完整情境、全部输入/输出、推测过程、接触声明、记录阶段、反馈及来源，也保留本版槽位的单位、内涵、对象与时间说明；可临时只看不同字段。同文或同名不合并，空文本与没有该字段分开显示。

每个展开例子提供「放入左侧对照」和「放入右侧对照」，按完整身份选择并展开、聚焦对应侧；同一例子不能占据两侧。两个下拉框同时显示原序号、完整身份和情境摘要，避免相同情境难以区分。对照两侧分别提供「返回例子」，展开并聚焦对应标题，不替换例子，也不清除当前筛选；目标不在筛选结果内时返回按钮禁用并说明原因。筛选可用于寻找另一侧，不会暗中换掉已选对象。

直接选择、字段对照和返回均不发出额外读取、保存或模型请求，不缓存对照对象或恢复保存批准。旧回调不能跨筛选、目标、读取轮次、历史或对照对象变化重新选中旧对象；读取失败保留草稿，旧版本和历史仍只读。返回保证精确例子身份，不承诺任意页面跳转后的像素位置恢复。

这是两个具体记录的对照，不是修订前后对照，也不自动判断正反例、控制变量或因果关系。预测尚无反馈时不补造答案；个人判断、资料答案、观察记录及 AI 建议分别标明。本版槽位说明不等于两次预测保存时的依据，历史依据仍通过各例子原有入口核对。

对照仅在本地读取，不更改草稿、服务器记录或保存批准；输出筛选不暗中改选这两个例子。编辑草稿、切换目标/文档/版本/快照、隐藏、卸载或重读后清除旧对照，防止把旧记录展示成新结果。读取失败保留原草稿，成功进入历史不继承草稿的选择。

## 保存与迭代

在「图文阅读」选择「渐构靶图」，或在材料图选择概念、判别模型、联结模型后点「为选中节点建立靶图」。目录搜索覆盖完整文档，不受画布分页限制。

1. 整理自己的上层表述和具体学习材料，明确确认后保存个人靶图。
2. 新增具体情境，填满所有必要输入、推测过程和预测输出，选择先记录预测并保存。
3. 对已保存预测填写对照结果，区分个人判断、资料答案、观察记录和 AI 建议，附来源说明。
4. 填写修订理由，更新当前表述并追加保存。查看预测时的上层表述可回到当时的完整快照，不以事后修订替代预测依据。

每次保存追加一条 `learning_attempts.task_kind = target_map` 记录，不改变正式节点、边、来源段落、已有个人记录或其他练习统计。仅常驻 SQLite Host 支持保存；动态 Host 明确报告持久化不可用。

保存后的预测情境、输入、过程、输出和接触声明冻结；已保存的对照内容也不能改写。使用过的槽位名称、单位、对象时间范围、陪域取值冻结，内涵、映射、条件与边界仍可修订。

需要重新拆分变量、纠正单位/对象时间或开始新的例组时，可在「另开一轮」填写理由并单独确认。必须先保存当前改动，新轮次只沿用当前已保存的上层与陪域，从空白例组开始；成功后才能修改槽位结构并另存。不会复制旧答案、将旧预测改回材料或抹去情境接触记录。旧轮次完整快照和预测依据继续保留，新轮起点可直接打开上一轮末版。此处是同一目标下的顺序轮次，不是任意分叉合并。

新轮次复用同一追加保存接口和事务，使用 `startRound: true`；严格绑定当前 `parentId`、文档/目标和图谱版本，并要求提交内容恰等于当前上层及空例组。记录以 `startsRound: true` 标明起点；与普通修订不可互换重试身份。不允许凭此标记直接提交修改后的模型或已知答案。未知方向、多个必要输入、同名独立身份与全部历史的已见情境限制仍然有效。

## 草稿和版本

- 从文档历史返回工作台时，同一文档、同一图谱版本恢复目标身份、目录类型、已提交搜索和页码；尚未提交的搜索文字仍保留，不擅自执行。再次明确选择材料节点可覆盖旧导航请求，已消费的请求不会在返回时把目标跳回去。
- 同一浏览器标签页刷新后，重新进入该文档的渐构靶图时恢复目标身份、目录类型、已提交搜索、页码和目录行内位置；未提交的搜索文字仍不自动执行。导航使用独立的 `sessionStorage` 键，按完整文档 ID 和图谱版本隔离，不改变本地草稿的持久化方式。当前窗口内较新的导航及明确的目标选择优先于存储内容，不重放此前已消费的目标选择命令。
- 导航只保存位置与读取意图，不缓存目录/目标/快照响应、模型正文或保存批准。恢复后重新读取目录与目标；修订列表的展开状态、页码与原列表首条身份保留，历史快照和预测依据不会自动打开。其他窗口追加修订后，旧列表仍须经过分页冲突检查，不能拿首页冒充原页。读取失败可重试，图谱版本变化不沿用其他版本的导航记录。修订列表内的精确阅读点及任意编辑区滚动位置暂不包含在此范围。
- 导航存储损坏、超长或身份不一致时，明确提示且不覆盖原内容，仍能选择目标和编辑草稿；存储不可写时提示刷新可能无法恢复，不阻止现有窗口操作。关闭或清理标签页会话后的恢复不作保证，不把导航缓存当作持久个人学习记录。
- 目标目录单独滚动，搜索与翻页不卷入列表；键盘可聚焦目录浏览。从历史返回、切换浏览方式、桌面与手机布局互换时，按完整目标身份和行内位置恢复目录阅读点，不按同名或固定像素猜测。新搜索、类型、页码、文档或图谱版本不沿用旧阅读点；隐藏或未读取成功的列表不会覆盖它。目录读取失败单独提示并可重试，不重读或改写个人草稿。
- 草稿按完整文档 ID、目标节点 ID、图谱版本保存在本地浏览器；未填写完的预测和对照草稿也能恢复。
- “本地草稿版本”可返回旧版未保存内容。旧版只读，新版内容不被旧草稿替换。
- 上下层定位也适用于历史快照和旧版只读草稿，不发起保存或模型请求。切换目标、文档、图谱版本、快照、草稿或浏览方式，以及重新读取时清除上次定位；已删除的例子、槽位或过期回调不会把焦点带到其他对象。上下层定位不等同于恢复整个编辑区的阅读位置。
- 图谱版本变化会阻止旧基准保存，须明确开启当前版本靶图；原个人快照和旧草稿保留。
- 另一窗口保存新修订后，本地草稿不覆盖它。读取并对照最新修订、明确确认后，才能以当前草稿追加新版本。
- 相同请求的重试幂等；本地存储损坏或容量不可用会提示，不自动清空旧数据。
- 个人修订记录每页 20 条，可向前后翻页，打开任意旧快照并返回未保存草稿。列表跨图谱版本展示，快照仍只读；翻页不恢复旧保存批准、不修改当前表述。
- 从文档历史返回或重新显示靶图时，同一文档、版本与目标恢复修订列表的展开状态和上次成功读取的页码。折叠时不预读旧页；展开后以原列表首条身份重新向 Host 读取，不缓存列表或快照。读取失败保留页码并可原样重试，不用首页冒充旧页；离开期间新增修订会明确报分页冲突，须手动重新读取。更换目标或图谱版本清除旧页码；保存新修订或另开一轮成功后返回新的第一页并保留展开状态。不自动打开历史快照，不恢复保存批准。
- 历史快照读取有独立进度、取消和按原记录重试。返回草稿、改选快照、切换目标/文档/版本、隐藏工作台或重读时，中止旧请求并拒绝迟到结果与错误；取消不会关闭此前已读快照，也不会恢复旧保存批准。读取失败保留草稿和此前快照，不以重新读取整个靶图代替重试单条记录。
- 从修订列表、预测依据或最新修订入口打开快照时，读取状态滚入视野并获得键盘焦点；完成或失败就地交接焦点，仅在新状态被遮挡时最小滚动，不抢走等待期间转到搜索框等控件的焦点。取消读取或返回草稿会定位到刚才离开草稿的那个入口，必要时展开相应例子或修订列表；连续查看多个旧快照仍保留最初的草稿入口。同一记录从不同入口打开也分别定位。若入口已不在当前历史页，回到草稿上层标题，不猜测其他同名记录或暗中翻页。这不是跨文档历史导航、整页刷新或任意编辑滚动位置恢复。
- 分页绑定列表最新记录的身份。其他窗口追加修订后，旧分页明确失效，需要重新读取列表，不静默跳过或重复记录。列表读取失败可重试，当前草稿保留。
- 从草稿打开历史快照或预测依据时，临时记录该入口在各层滚动容器中的阅读位置。取消或返回时按入口完整身份及相对位置恢复，不再一律将入口放到屏幕中央；内容高度变化后仍按入口定位，窗口变矮时将其限制在可见区域。失败重试及连续阅读多个快照保留最初位置。滚动容器更换、原入口缺失或不明确时沿用可见的焦点回退，不操作已移除的容器；文档、目标、图谱版本或草稿基准变化、隐藏、卸载和重读使旧位置失效。该位置只在本次阅读往返中保留，不存入草稿或服务器，不恢复保存批准，也不是整页刷新或任意编辑位置恢复。

## 上层表述对照

打开一条历史快照后，可切换「快照内容 / 对照上层表述」。对照将该快照与当前未保存草稿的标题、类型、规律、条件、边界、槽位和输出陪域逐字段并列；默认只显示不同字段，也可显示相同字段。每侧明确标记快照/草稿基线身份和知识图版本，跨版本时单独提示。

槽位与陪域取值按完整 ID 配对，不按同名、顺序或近义词合并；身份或顺序变化单列，缺失字段与空文本分开。单位、对象时间、限定语、空格、运算符及 Unicode 表述保持原样，不做语义归一化。长文本可滚动、键盘读取，不把截断内容拿来判定相同。

此处仅对照上层字段，不比较下层例子、预测或反馈。上层逐字相同不代表下层相同，也不证明模型正确、语义等价或掌握。对照不请求 AI、不追加记录、不填回草稿，也不替代冲突处理中的人工对照确认。返回时草稿不变；切换快照、目标、版本、隐藏或重读时清除旧对照，失败不把上一次对照冒充新结果。

## 例子记录对照

同一历史快照还可选择「对照例子记录」，按完整例子 ID 对照它与当前草稿的情境、接触声明、输入、推测过程、预测或材料输出及已填写的对照结果。相同情境不合并不同身份；增删和例子、绑定槽位的次序变化可见。通过例子选择菜单逐条读取，默认选中首个有差异的例子并仅显示不同字段，也可显示全部字段；最多 80 个合并后的身份只渲染当前一例的字段。

输入输出按各自槽位 ID 配对，每侧独立解析该版本的槽位名称、内涵、单位、对象时间和对应陪域取值，不把草稿的新含义套给旧材料。同名异身份、空值与缺失、完整文字和限定语均保留。材料、预测和对照阶段分开显示；只有已进入对照阶段才列出结果来源类型、正文及来源说明，个人判断、资料答案、观察记录和 AI 建议不混称独立验证。

该对照不包含上层规律或预测时的上层依据；上层字段和下述预测依据有各自入口。例子字段相同不代表依据相同、预测正确或知识成立。浏览和筛选不发送额外请求、不修改草稿或已存记录、不恢复任何保存批准，也不将新旧记录合并。版本、请求和旧回调隔离沿用上层对照的边界。

## 两份历史快照对照

查看一份已保存快照后，可将其固定为对照快照，再从修订记录中打开另一份，选择「对照对象」中的固定快照。上层表述与例子记录两个视图均可使用这个对象，不必将当前未保存草稿改成其中一侧。两侧显示完整记录身份及各自知识图版本，左侧是当前查看的快照，右侧是固定快照，位置不暗示时间先后、修订改进或验证结论。同一记录不能与自身配对。

上层沿用逐字段精确比较；例子仍按完整例子、槽位、陪域身份配对，独立解析每侧的单位、对象时间和全部输入输出，保留缺失、空值、顺序及四类反馈来源。默认只显示差异，可显示相同字段。一次仅渲染选中的例子，不展开全部历史模型。两个相同字段不意味着同一语义、正确预测或独立验证，跨知识图版本会明确提示。

固定只保留本次窗口中已经明确读取的一个完整快照，不缓存到会话导航或草稿，也不自动读取其他历史。改选历史快照会退出旧对照；读取失败或取消保留原固定对象与草稿，不把旧对照冒充新结果。取消固定、返回草稿、换文档/目标/版本/草稿基线、隐藏、卸载或重读会清除固定对象和对照。浏览、切换字段及筛选无新增请求或写入，不恢复保存批准；迟到响应与旧回调不能重新套用配对。

此处比较的是两份保存快照自身的字段，不自动追溯其中每个例子的首次预测依据，不合并历史或向草稿填入内容。任意两个历史预测依据的专用比较仍不在此范围。

## 预测依据对照

已保存的预测或对照例子可选择「对照预测依据与草稿」，明确读取该例子首次保存预测时的完整快照，并直接对照其上层字段与当前草稿。标题列出预测例子、所属修订、依据快照和双方知识图版本；完整预测情境可展开。默认只看不同字段，桌面并排、手机逐字段堆叠，返回时保留草稿并回到原入口。

在历史快照的已存例子中，还可选择「对照预测依据与此快照」。左侧读取这个历史例子自己的首次预测依据，右侧固定为刚才选择的历史快照，不使用当前草稿或最新修订。同一轮后续反馈、另一轮复用例子 ID、当前图谱版本变化，都不能把右侧换成别的记录。依据就是所选快照自身时，该入口禁用，不发起自配对请求。

依据读取通过全部身份和绑定校验后，才安装这对历史对象；失败或取消不更换原固定对象。可以「返回所选历史快照」重新读取右侧记录，失败可重试，仍然只读。返回草稿保留原文稿字节并撤销保存批准。改为「对照例子记录」后仅比较这两份快照自身的例子字段，明确退出预测依据专用视图，不把后来的反馈放到首次预测一侧；改用草稿或普通上层对照也退出专用标识。

依据必须来自当前正在查看的记录：历史快照使用自己的 `bases`，不能使用最新修订中同名例子的引用。旧轮次不再存在于当前例组时仍可查看；另一轮复用同一例子 ID 也不覆盖旧依据。未保存预测、缺少有效引用或与已保存预测不一致的草稿，不会被自动套上当前表述。

读取同时核对文档、目标、记录身份、图谱版本、来源标记、首次预测阶段、原始情境/输入/过程/输出、绑定槽位与陪域字段及自指依据引用。缺失、串用、循环或冲突明确报错，不递归追逐引用、不猜测替代记录，也不把事后反馈当成预测。内涵与规律允许在后续修订中改变，正是此对照需要暴露的差异。

失败可按原依据和原对照意图重试，取消、返回、目标/文档/版本切换、隐藏、卸载和新读取使迟到结果失效；读取期间草稿变化也不能自动套用旧配对。仅显式打开时读取一条历史记录，筛选不增加请求。后续修订不能倒算为当时的依据；记录身份对应不证明预测正确、语义相容或独立验证。不写正式图谱、不追加个人记录、不改草稿或恢复保存批准。此处不是任意两个历史预测依据的批量比较。

## 语义边界

靶图记录的是学习者的表述，不是对概念、定律或事例的认证。字段齐全、AI 建议、材料配对、来源说明、自报未见、一次结果一致，都不证明正确、因果成立、独立验证或掌握。

系统不执行公式，不推断单位相容，不补齐未知方向，不合成概率。它可以拦住缺失必要输入、身份串用、旧材料改称新预测、事后改写和版本冲突，但不会自动判断“条件满足”或“这个推测成立”。保存自报未见的情境时会核对本目标的全部历史情境文字，不限于最近 20 条；比较仅使用 Unicode NFC 和去除首尾空白，保留运算符、指数、标点及内部词元间隔，不擅自判定数学表达等价。文字不同仍不证明真正新颖。

## 容量和未覆盖范围

单图最多输入、输出各 8 个槽位、80 个陪域取值、40 个例子；核心 JSON 上限 240000 个 JavaScript 字符。修订列表每页只读取 20 条元信息，完整快照在明确选择后按身份读取，不批量下载全部历史模型。新入口使用完整身份，文档和目标标识上限 4096 个字符，不截断、去除首尾空白或合并同名；不能外推其他写入 API 已支持相同范围。

当前未实现任意横向中间变量、纵向中层类别的组合画布、跨靶图组合、任意历史分叉与合并、从原文或 AI 自动填入个人答案，以及独立验证或自动掌握判定。

## 验证

`npm run test:kg-target-map` 包含纯契约、生成产物一致性、真实 Host HTTP 与隔离 SQLite、生产组件状态测试。它也是完整 `npm test` 的组成部分。交付还需浏览器桌面、390px 手机验收及扩展签名、payload 一致性校验。
