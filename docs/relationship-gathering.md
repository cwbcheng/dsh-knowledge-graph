# 关系聚拢

点击节点详情中的“聚拢相关”，或画布工具栏的聚拢图标，以该节点为中心查看直接相连的节点。点击邻居后可选择“以此为中心”，继续沿关系阅读。箭头按钮返回上个中心，关闭按钮退出聚拢并恢复原来的全图镜头、选择和原文位置。

## 范围与完整性

- 按整份 canonical 文档中的精确节点 ID 查询，不受当前 800/2000 节点窗口、章节筛选影响。
- 默认一跳、双向，支持入边、出边和关系类型筛选。外圈只是布局位置，不代表二跳关系。
- 每批读取 80 个邻居，明确显示已加载数量、邻居总数和“继续展开”。80 是展示批量，不是总量或模型限制。
- 同时返回已加载邻居之间的已有关系；不调用 AI、不推测新关系、不写入图数据。
- 原文和聚拢节点保持双向定位。窗口外节点的编辑入口不转交给原窗口；原窗口内关系通过完整的端点和关系类型映射，不能使用子图数组下标编辑原图。
- 查询和分页绑定文档 revision。版本不一致会拒绝请求；当前基础图或窗口变化时退出旧聚拢并提示，避免继续使用过期节点。

## 布局与性能

节点使用实际测量尺寸，中心固定在原点，邻居分布在无重叠的环上。局部布局复用现有 Worker 和加载阶段；过密的关系标签在悬停或选中时显示。进入或换中心时播放短动画，遵循系统“减少动态效果”设置。

基础视图保持挂载并冻结其渲染输入，不重新布局、不重置镜头。聚拢使用独立的选中状态；快速切换和退出会中止 HTTP 请求并拒绝迟到结果。动态 sandbox 的传输不能保证底层取消时，序号和 abort 检查仍保证迟到结果不能写回 UI。

## 验证

- `npm test`：包含邻域查询、SQL/动态 Host 一致性、分页完整性、版本保护、异步竞态、布局无重叠和既有布局/缩放/加载回归。
- `node scripts/kg-neighborhood-ui-fixture.mjs`：启动隔离浏览器测试页面，使用临时 SQLite、真实持久化 HTTP handler 和生成的 viewer；不调用模型，不连接 DSH 生产数据库。停止时清理临时数据库。
- 浏览器 fixture 提供 4800 个节点和 501 个跨窗口邻居，可用 `?limit=2000` 检查大窗口；支持延迟响应、孤立节点、文档版本变化和卸载场景。

部署需要同时更新 Host 和 Client。已有 DSH 进程需要在保存/暂停进行中的任务后重启，浏览器需要刷新；单独刷新旧进程不会新增后端查询接口。
