# 界面文案规范

界面先回答三个问题：这里能做什么、点击后会发生什么、下一步该做什么。以用户的阅读和学习任务命名入口，以具体动作命名按钮。

## 写法

- 一个功能只用一个名称。按钮、页签、标题、提示、可访问名称和使用说明同步更新。
- 保留《学习观》的专有名词和领域术语，包括判别模型、联结模型、渐构靶图、内涵、陪域、判别上料/下料、联结上料/下料和下上对照。可以在旁边解释含义，不能用通俗别名替换概念名称；槽位与变量也不混称。
- 按钮用“动作＋对象”，如“生成知识图”“删除书签”。页签和分组使用同一层级的任务名称。
- 把结果和下一步放在提示开头。错误说明包含补救动作；进度只描述当前任务，不承诺固定完成时间。
- 帮助文字先说用户需要理解的影响。API、存储和部署细节留在开发文档；格式、单位、版本和来源影响用户选择时保留。
- 用简短标题帮助扫读，详细限制放在相关操作旁。删除说明指出对象和范围，保存说明区分草稿、个人记录与正式知识图。
- 名称和语法的重复形成一致性；同级标题保持并列；提示紧邻相关操作；用明确的动词区分阅读、生成、核对和修改。
- 原文可定位、原文支持、外部事实核查是三种状态。AI 建议、用户自述和练习自评必须明确标注，不写成已验证或已掌握。

这些写法参考 [Steve Krug 的《Don't Make Me Think》](https://sensible.com/dont-make-me-think/)及其[官方样章](https://ptgmedia.pearsoncmg.com/images/9780321965516/samplepages/0321965515.pdf)中关于扫读、清楚导航和删减冗余文字的原则；将 Robin Williams 的《写给大家看的设计书》中对比、重复、对齐和亲密性的原则用于文案层级与分组，见[出版方介绍](https://www.informit.com/store/non-designers-design-book-9780133966152)。这是界面措辞的应用，不改变两本书的原意，也不把文案调整当作视觉布局改版。

“联结模型”对应《学习观》的 `connection_model`，界面和本体使用同一专有名称。渐构靶图、判别/联结材料及上下层坐标也沿用原书术语。原书名称、本体标签、模型提示词、用户原文和服务返回的诊断按其来源保留，避免改变概念含义。

联结模型详情的「阅读」组包含下上对照、模型比较；「学习」组包含我的理解、情境预测、两步推测、学习记录；「核对」组包含待补充内容、核对方向、核对结构。「原文依据」是各组共用的独立阅读栏，打开或收起它不切换当前任务。条件、映射、边界各自紧邻来源提示，未定角色单独展示。面板宽度不足时原文上下排列，输入输出区域按剩余内容宽度重排。

切出联结模型工作区时，子面板暂停读取并取消尚未完成的读取，不接收迟到结果或聚焦隐藏控件；返回时重新读取当前任务。所选任务和未保存的私人草稿保留，结构写入仍需当前版本的预览和明确确认。

同一模型的分支、字段命中或材料详情重读时，结构编辑器保留当前工作台内的私人草稿；当前详情不可用期间隐藏编辑控件并暂停读取。浏览器缓存写入失败的警告在返回结构核对后继续显示，成功缓存后才清除；保留内存草稿不代表已保存，也不替代当前版本校验、预览及明确确认。关闭或刷新页面仍可能丢失未能缓存的内容。

「我的理解」也在同一模型详情重读期间保留当前面板内的私人表述、换行、条件、边界及关联练习选择；未取得当前详情及服务版本支持时停用面板。恢复后仍按原草稿版本和个人记录基准校验，不自动改用新版、不自动保存为学习记录或正式图谱。浏览器无法缓存的内容仍只存在于当前窗口。

情境预测和反例挑战在同一模型详情重读期间保留当前练习面板内的未提交输入、换行、条件、失效边界和原文接触自述；当前详情不可用时停用练习读取与控件。原草稿版本及保存、对照、复盘的确认边界保持，不自动提交私人输入。无法缓存的内容仍可能在关闭或刷新页面后丢失。

验证结果的未保存草稿由当前练习窗口保留内存兜底，切换阅读或详情重读后恢复原来源类型、内容、条件、比较、自述诊断及更正基准。草稿按文档、模型和预测身份隔离，恢复不改用新的预测版本，也不自动确认观察、保存结果或证明模型成立。子面板隐藏期间仍取消读取；关闭或刷新窗口不保证恢复无法缓存的内容。

结果草稿的缓存警告按当前草稿与实际缓存是否一致显示；恢复内存草稿后仍提醒保留窗口，当前草稿成功缓存后清除。其他预测的空草稿不继承该警告；缓存警告与读取、保存错误分别呈现，缓存成功不表示结果已提交或得到核验。

「我的理解」的缓存警告同样反映当前私人表述及关联练习是否已缓存：重新读取个人记录不清除未缓存警告，成功缓存后不继续误报。空白的另一模型不继承警告；缓存提示不代替来源版本、个人记录基准或保存错误，也不表示已保存个人记录。

情境预测和反例挑战的缓存提示分别核对当前预测草稿及所选记录的未保存复盘，包括仅调整原文接触自述或复盘选项的草稿；重新读取、返回练习及已保存复盘旁保留的冲突草稿仍按实际缓存显示。成功缓存后清除提示，服务读取或保存错误独立显示，不将缓存成功视为提交或验证成功。

仅修改原文接触自述、复盘判断或自评也算未保存的私人选择：关闭窗口时提示，另开预测时要求放弃确认；取消后原选择保留。原文接触自述草稿可从已选记录返回，来源版本变化时不静默覆盖；未改动或改回默认值的空白选择不触发这些保护，已保存复盘的选项不被当成新草稿。

关闭保护还检查当前练习窗口已保留的其他私人预测和复盘，切换历史记录或模型不会让这些草稿退出检查。各草稿仍按原身份恢复；不会仅因浏览过其他记录而提示。检查本身不写缓存、学习记录或正式图谱，也不保证未能缓存的内容在关闭/刷新后可以恢复。

复盘保存回应只清理仍与本次提交一致的草稿；当前窗口或浏览器缓存已有较新内容时继续保留，无法比较缓存时也不清理。重新读取后，已保存的原复盘保持不可修改，较新的私人表述作为未保存副本展示，不自动合并、覆盖或提交为另一条正式记录。

预测保存回应丢失后的主动重读，也只确认仍对应当前草稿与所选记录的最新读取；后来编辑、切换记录或开始新操作会使旧回应失效。内存或缓存已有较新预测时不清理、不跳转到旧记录，原来源版本与未保存内容保持；未改动的提交中缓存仍可在重新打开后确认原保存结果。

目录和详情在工作区首次打开时读取，隐藏期间取消未完成的读取并延后新的读取。返回时只补齐未完成或失败的目录、详情；同一文档、版本和筛选范围内已读取的内容保持挂载，避免丢失内存中的私人草稿。版本、模型、分页、筛选变化或主动重新读取仍会使对应内容失效；成功响应不写入浏览状态缓存。隐藏不会撤销用户已明确发起的方向预览或保存。

方向预览或确认保存尚未返回时，连续触发只受理一次，避免重复排队产生误导性的版本失败。请求失败保留已选角色并允许重试；确认保存失败后仍须重新预览再明确确认，服务端版本校验始终生效。

方向草稿保留开始修改时的图谱版本、端点身份和映射引文。外部版本更新后单独展示旧选择及旧引文，当前控件显示新版角色；旧草稿不能直接预览或保存到新版。用户明确放弃旧版方向修改后，才可按当前内容重新核对。旧引文不使用旧段落编号跳转当前原文，已移除的端点也保留在旧草稿提示中。

新版模型详情读取中、读取失败或整个模型已移除时，旧方向修改及其引文仍可查看，放弃入口不依赖已不可用的「核对方向」任务。放弃继续要求明确确认；查看或放弃草稿不会修改图谱或学习记录。

模型详情读取失败后，错误旁提供「重试读取模型详情」，只重试当前模型及材料页，保留目录、原文栏和未保存的方向选择。重试不要求放弃草稿，也不预览或保存修改；回应仍须符合当前文档、模型与版本。主动「重新读取模型」仍沿用原有的草稿放弃确认。

目录查询或翻页读取失败时，错误旁提供「重试读取模型目录」，保留当前筛选、页码、正在阅读的模型、原文栏和未保存修改，只重读失败目录。重试后焦点回到持续可用的搜索框；变更文档、版本、筛选或页码后，旧错误和重试入口立即隐藏，输入等待更新期间也不展示旧查询的错误。目录重试不触发全图刷新、详情重读或任何写入。

已选模型读取中或失败时，详情保留所选节点身份并标注「请求版本」；只有读取成功并校验后才显示「版本」。读取失败不显示未选择模型的提示，原文栏指向同一个详情重试入口。文档、版本、模型或材料页切换后，旧读取错误立即退出当前上下文，不将旧错误归于新选择。

条件、映射和边界的「旁侧核对」在原文栏展示所选字段记录的完整引文、备注、分支身份及来源状态，保留当前任务。「在知识图与原文中定位」才切换阅读视图；重复引文无法唯一定位时仍须明确提示，不把旁侧展示当作已匹配或已核验。切换模型、版本或重读后不沿用旧字段引用。

联结模型查找栏使用持续可见的字段标签和当前筛选摘要。关键词、章节、待核对、概念及作用可分别清除，也可一次清除全部；概念筛选保留节点身份，清除概念时同时清除依赖它的作用。清除只更新目录并返回第一页，保留正在阅读的模型、当前任务、原文栏及未保存的修改；键盘焦点返回搜索框。搜索覆盖已记录的模型、概念、条件、映射和边界文字，命中不代表适用性验证。输入尚在等待更新时不把旧计数或旧空结果当作新结果。

章节选项来自整份资料，同一文档版本重新筛选时保留名称；版本变化或主动重读后重新获取，不把章节元数据写入浏览状态缓存。零结果区分「没有匹配的联结模型」「当前页没有模型」「这份资料尚无联结模型」，分别提供减少筛选、返回第一页或继续阅读的下一步；读取失败继续显示错误。

这轮查找交互参考 [Linear 2026 年 3 月界面更新](https://linear.app/changelog/2026-03-12-ui-refresh)的一致层级，以及 Carbon 的[筛选](https://www.carbondesignsystem.com/building-blocks/core/patterns/filtering)和[空状态](https://www.carbondesignsystem.com/building-blocks/core/patterns/empty-states)规范。主辅阅读布局另与 [Material 的标准布局](https://m3.material.io/foundations/layout/canonical-examples/overview)对照。来源是产品设计实践，不能代替本项目的可用性测试或证明任务完成率提升。

联结模型所在浮窗跟随当前可用窗口大小收拢，四边和关闭按钮保持可达；目录、正文和原文依据按各自容器宽度重排。临时缩窄不覆盖用户保存的尺寸，恢复宽屏时还原布局；只有主动拖动或调整大小才保存位置。窗口变化不重建正文，不清除当前模型、任务、原文依据或未提交编辑。验收同时检查浮窗相对浏览器的边界，不能只看内容内部是否横向溢出。

这项适配延续 [Linear 2026 年界面设计说明](https://linear.app/now/behind-the-latest-design-refresh)的正文优先和稳定导航原则，并参考 [Material 3 列表—详情布局](https://developer.android.com/develop/ui/compose/layouts/adaptive/list-detail)按可用空间安排主辅内容的做法；本项目使用 Web 容器查询和浮窗几何适配，不引入 Android 组件。

目录当前选中行提供「阅读当前模型」入口，主动将阅读位置和键盘焦点移到详情；详情提供「返回模型目录」，回到当前页的选中行。当前模型不在本页时返回搜索框，不自动清除筛选或更换分页。仅选择模型和异步读取不会主动移动焦点；这两个往返操作不重建详情，不改变当前任务、原文栏或未保存草稿。

模型目录分页放在列表滚动区域上方，无需滚过整页条目才能翻页。主动翻页时焦点立即移入持续挂载的目录，读取结果不再次抢焦点；列表回到新页开头，详情、原文和未保存修改保留。关键词等待更新时暂停旧页分页，过期或连续回调不重复翻页。读取失败时仍可按原条件重试或返回上一页。

模型比较的候选目录在翻页、加载和读取失败时保持挂载。分页入口位于候选列表上方，主动翻页立即把焦点放到候选区，读取完成后可用 Tab 进入本页首项；异步响应不抢焦点。分页只改变候选目录，保留已选模型 A/B、条件与引文、旁侧原文和未提交修改；查询等待更新时暂停旧页分页，失败后可返回上一页或重试读取比较候选。

比较关键词尚在等待更新时，候选区标为忙碌并提示「正在更新比较搜索」，暂不显示旧计数、旧候选或旧零结果操作；旧候选回调也不能更换模型。已明确选择的模型 A/B 及展开的比较依据继续保留，输入和异步回应不主动移动焦点。新查询读取结束后才显示对应计数与候选。

比较候选读取失败后，错误旁提供「重试读取比较候选」，按原查询、共享概念筛选和页码重读候选；已选模型 A/B、已展开的条件来源、端点及材料引文、原文上下文保持挂载。重试同步聚焦搜索框，回应不抢焦点，也不取消独立的模型比较或原文定位。查询等待更新或文档、版本、候选范围变化后，旧错误和重试操作不再生效；「重新读取模型比较」仍重读候选与已选模型对。

模型对读取中或失败时，「本次比较对象」继续展示明确选择的模型 A/B 节点身份及「请求版本」，不依赖候选是否仍在当前页。只有回应通过文档、版本和两侧模型身份校验后，才显示「版本」、模型状态及比较依据。更换模型 B、版本或主动重读立即隐藏旧结果和旧错误；更换模型 A 或文档时清除原有 B 选择，不把它自动带入新的比较。候选翻页、筛选和独立重试仍保留本次比较对象。

模型对读取失败时，错误旁提供「重试读取比较模型对」，只重读明确选择的 A/B，保留候选查询、共享概念筛选、页码及独立候选读取。主动重试同步将焦点放到持续挂载的读取状态区，回应不抢回焦点；连续回调只受理一次，身份、版本、全量重读或工作区状态改变后旧回调失效。重试后仍须通过当前身份与版本校验，才展示条件、映射、引文和模型状态；不根据候选顺序推测另一侧模型，也不写入图谱或学习记录。

「同名但身份不同的端点」区分展示名称与概念身份：同一概念在两侧使用不同槽位名称时，不抵扣其他身份之间的同名组合。最多展示前 50 组，总数仍保留全部匹配；名称相同不证明概念相同或模型等价，未定角色和来源继续按记录展示。

同一概念在多个槽位中有不同名称时，全部已记录名称都参与同名查找，不由第一个槽位决定是否匹配。多个名称命中同一对概念身份时只计一组，展示实际匹配的两侧名称；完整槽位、角色、单位、时间状态和引文仍在各模型中分别保留。

两步推测的第 2 步模型候选沿用同一分页交互：候选区及分页入口在读取和失败时保留，主动翻页同步聚焦候选区并回到列表开头，回应不抢回焦点。分页只读取当前筛选的候选目录，保留已选模型对、分支、槽位承接、私人草稿及其检查结果；检查仍仅表示草稿字段情况，不能证明相容性、预测结果或掌握程度。切换第 2 步模型继续要求明确确认。

两步推测的候选读取失败后，错误旁提供「重试读取第 2 步候选」，按原查询、输出承接筛选和页码重读候选；保留模型对、私人草稿及其检查结果，不触发全量重读。重试时焦点回到搜索框，回应不再次移动焦点；查询等待更新、文档、版本或候选范围改变后，旧错误和重试操作不再生效。原有「重新读取两步推测模型」仍重读模型对并清除旧检查结果。

两步模型读取中或失败时，已选两步的私人草稿继续只读展示：模型、分支与槽位身份，已知输入及依据、明确选择的承接来源、核对文字、预测、条件和应用过程均保留；未使用的另一种输入来源文字另行标明。草稿来源版本与请求模型版本分别展示，只有模型回应通过身份与版本校验才显示已读取版本及结构编辑控件。保留文字不使用旧模型名称或旧原文链接，不代表当前结构、映射相容性或预测已经核验。导出仍可使用；旧来源版本必须重新对照并明确确认，才允许检查。主动重读或更换模型、文档、版本时立即隔离旧模型回应与读取错误，不改写草稿缓存。

两步模型读取失败时，错误明确标注对象，并在旁提供「重试读取两步模型」，只重读明确选择的模型对，保留第 2 步候选的查询、筛选与页码及全部私人草稿。主动重试同步将焦点放到持续挂载的读取状态区，回应不再次移动焦点；连续点击只受理一次，文档、版本、模型对、重读或工作区状态变化后旧重试不再生效。重试不自动检查草稿、不确认使用新版，也不写入图谱或学习记录。
